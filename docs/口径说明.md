# 口径说明

面试时按本文件讲即可。代码中的过滤与这里保持一致。

## 数据源

默认 `source: baostock`，从 BaoStock 拉取**真实 A 股**日线。股票池为接口返回的**当前**沪深300 成分前 `max_stocks` 只（默认 50）。这是幸存者偏差：回看期内后来才进指数、或中途被剔除的股票没有按当日成分处理。

- 未复权行情：`adjustflag=3`
- 后复权收盘：`adjustflag=2`，`adj_factor = 后复权收盘 / 未复权收盘`
- 估值：日频 `peTTM`
- 行业、上市日：`query_stock_industry`、`query_stock_basic`
- 规模：BaoStock 无日频总市值，中性化用 `log(成交额)` 作流动性/规模代理

`source: tushare` 需要 token；`source: sample` 仅用于无网调试。

## 价格

- **复权**：`close_used = close * adj_factor / 期末 adj_factor`
- **对照 `no_adj`**：直接用未复权收盘价

## 样本

默认同时满足才进入 `in_sample`：

- 上市已满 180 个自然日
- 当日 `isST != 1`
- 当日未停牌（`tradestatus != 1`）
- 主板 `|pct_chg| < 9.5%`；创业板 / 科创板 `< 19.5%`

对照 `no_limit_filter` 会关掉涨跌停过滤。

## 因子

- **动量**：`P_{t-5} / P_{t-25} - 1`（过去 20 日收益、跳过最近 5 日）
- **EP**：`1 / pe_ttm`。`pe_ttm <= 0` 记为缺失。未做财报公告日的严格时点对齐。

## 中性化

每个交易日截面：MAD 去极值 → Z-Score → 对行业哑变量与 `log(成交额)` 回归取残差。评价用 `mom_n`、`ep_n`。

## 未来收益

用同一套 `close_used` 计算 1 / 5 / 20 日远期收益。无交易成本、无涨跌停无法成交仿真。**Q5-Q1 只用于看分层，不能当成策略收益。**
