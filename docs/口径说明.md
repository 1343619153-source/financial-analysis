# 口径说明

面试时按本文件讲即可。代码中的过滤与这里保持一致。

## 价格

- **复权**：`close_used = close * adj_factor / 期末 adj_factor`，把历史价格落到样本期末口径，避免拆分把动量打乱。
- **对照 `no_adj`**：直接用未复权收盘价算因子和未来收益，用于展示口径错误会如何污染 IC。

## 样本

默认同时满足才进入 `in_sample`：

- 上市已满 180 个自然日
- 名称不含 ST（样例里用 `is_st` 标记）
- 当日未停牌（成交量为 0 视为停牌）
- 当日 `|pct_chg| < 9.5%`（涨跌停近似；创业板 20% 未单独处理）

对照 `no_limit_filter` 会关掉涨跌停过滤。

## 因子

- **动量**：`P_{t-5} / P_{t-25} - 1`，即过去 20 日收益、再跳过最近 5 日，减轻短期反转噪声。
- **EP**：`1 / pe_ttm`。`pe_ttm <= 0` 记为缺失。这是用现成估值字段的近似，不是逐季利润表的严格时点对齐。

若使用 Tushare：`pe_ttm` 来自 `daily_basic`，仍可能含公告滞后，完整 PIT 需要对齐实际披露日，本项目未做。

## 中性化

每个交易日截面：

1. MAD 去极值（约 3 倍稳健标准差）
2. Z-Score
3. 对行业哑变量与 `log(total_mv)` 回归，取残差

评价用的是残差 `mom_n`、`ep_n`。

## 未来收益

用同一套 `close_used` 计算 1 / 5 / 20 日远期收益。没有模拟涨跌停无法成交、也没有交易成本。因此 **Q5-Q1 只能比较分层，不能当成策略收益**。

## Tushare 股票池

`source: tushare` 时，用区间**最后一天**的沪深300 成分，再截断为 `tushare_max_stocks`。这会把后来才进指数、或中途被剔除的股票处理错，属于幸存者偏差。样例数据没有这个问题。改进方向：按月展开 `index_weight`，只保留当日仍在指数内的股票。

## 样例数据

内置 40 只虚拟股票、四个行业、约两年工作日。含一次中段复权因子跳变、少数停牌和涨跌停、一只 ST。用于验证代码链路，**不能当作真实市场结论**。
