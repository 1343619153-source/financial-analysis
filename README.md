# A 股投研底表与单因子评价

面向量化 / 投研数据实习：把行情做成可追溯的日频底表，计算 **动量** 和 **EP**，输出 Rank IC 与五分组报告，交给研究组判断因子是否备选。**不是交易策略，不产出买卖信号。**

当前默认用内置样例数据（无需 Tushare token）。本次仓库中的数字均来自该样例，用来验证链路是否跑通，**不能当成真实 A 股的因子结论**。

仓库地址：https://github.com/1343619153-source/financial-analysis

---

## 做了什么

**数据对接。** 将日线、复权因子、市值、估值（`pe_ttm`）收成一张「交易日 × 股票」底表。默认 40 只虚拟股、四个行业、2021-01-01 至 2022-12-31 工作日；代码已留 Tushare 接口，换成沪深 300 真实行情后仍走同一套流程。

**口径处理。** 价格用复权收盘价。样本默认剔除 ST、停牌、涨跌停（`|pct_chg| ≥ 9.5%`）、上市不满 180 日。动量为过去 20 日收益并跳过最近 5 日；EP 为 `1 / pe_ttm`（市盈率为负或缺失则不算）。每个交易日做 MAD 去极值、Z-Score，再对行业哑变量和对数市值回归取残差。

**评价与交付。** 不算年化、不算夏普。交付指标为：Rank IC（因子与未来 1 / 5 / 20 日收益的秩相关）、五分组高低组收益差、换手。另做两组对照：不复权、不过滤涨跌停，用来说明同一因子在不同数据规则下评价是否变化。

详细规则见 [`docs/口径说明.md`](docs/口径说明.md)。完整表与图见本地运行后的 `reports/factor_report.md`。

## 结果是什么样

主方案 `baseline`（复权 + 过滤涨跌停，约 1.95 万条样本、约 490 个交易日）：

| 因子 | 持有期 | Rank IC 均值 | ICIR | 最高组−最低组 | 日均换手 |
| --- | --- | --- | --- | --- | --- |
| 动量 | 1 日 | −0.008 | −0.05 | −0.05% | 40% |
| 动量 | 5 日 | −0.001 | 0.00 | +0.02% | 40% |
| 动量 | 20 日 | +0.008 | +0.05 | +0.31% | 40% |
| EP | 1 日 | −0.005 | −0.03 | −0.01% | 80% |
| EP | 5 日 | 0.000 | 0.00 | 0 | 80% |
| EP | 20 日 | +0.005 | +0.03 | −0.02% | 80% |

口径对照：

- **不复权 `no_adj`：** 样本行数与 baseline 相同（19501）。IC 均值几乎不变；20 日动量高低组差由 0.31% 变为 0.37%。
- **不过滤涨跌停 `no_limit_filter`：** 样本增至 20316。动量 1 日 Rank IC 由 −0.008 变为 −0.005，20 日 IC 由 0.008 变为 0.009，方向不变、数值小幅偏移。

累计 Rank IC 在 0 附近波动，五分组没有稳定单调分层。

## 分析结果

**IC 接近 0 是预期，不是程序算错。** 样例价格接近随机游走，没有人为植入有效因子。研究侧通常要求 Rank IC 持续离开 0、ICIR 明显大于 0 才进入备选。这里 ICIR 都在 ±0.06 以内，表示**几乎没有截面预测力**。结论：链路跑通，两因子在该样例上**不应进入因子库**。

**分层同样不支持「能用」。** 1 日、5 日高低组差接近 0；动量 20 日约 0.31%，但 ICIR 仅 0.05，不稳定。EP 高低组差在 0 附近正负跳动，没有单调性。

**换手说明排序很「吵」。** 动量日均约 40% 换组，EP 约 80%。即使以后在真实行情上 IC 变好，高换手也会抬高摩擦。有效性和可执行性要分开看。

**口径对照里，有信息量的是涨跌停过滤。** 关闭过滤后多约 800 行，IC 发生小偏移：涨跌停当日的账面收益往往无法成交，不过滤会把「账上有、实盘没有」的收益算进去。不复权对照几乎拉不开平均 IC，是因为样例里拆分只有一天，被近 500 个交易日平均掉；真实行情应对着除权日单独检查，不能只看全样本一个平均数。

**不要把 Q5−Q1 说成策略收益。** 未计入交易成本，也未模拟涨跌停无法成交。该差值只用于看分层。

## 如何运行

需要 Python 3.10+。

```powershell
cd "D:\Financial analysis"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m src.main
```

跑完查看：

- `reports/factor_report.md`
- `data/processed/panel_baseline.parquet`

### 换成真实 A 股数据

1. 复制 `.env.example` 为 `.env`，填入 `TUSHARE_TOKEN`
2. 将 `config.yaml` 中 `source: sample` 改为 `source: tushare`
3. 再运行 `python -m src.main`

Tushare 默认只取沪深 300 前 40 只（`tushare_max_stocks`）。成分使用区间末日截面，存在幸存者偏差，见口径说明。
